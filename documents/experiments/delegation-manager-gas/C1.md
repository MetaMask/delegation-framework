# C1 — Hoisted EIP-712 domain separator

## Purpose

Reuse `_domainSeparatorV4()` once per outer `redeemDelegations` batch instead of calling `getDomainHash()` per delegation signature check.

## Semantic delta

- **Retained:** All hook phases, validation order, events, `executeFromExecutor` forwarding.
- **Lost:** None (behavior-preserving).
