# C5 — Lean redemption events (observable delta)

## Purpose

Emit `RedeemedDelegationLean(rootDelegator, redeemer, delegationHash)` instead of canonical `RedeemedDelegation` carrying the full `Delegation` struct in log data.

## Semantic delta

- **Retained:** Execution, hooks, validation, forwarding.
- **Lost:** On-chain full delegation payload in redemption logs; indexers must recover fields from signed payloads off-chain.

## Benchmark

```bash
forge test --isolate -vv --match-contract CompatibleAblationGasBenchmark --match-test test_bench_C5
```

| Variant | Exec gas | Est. tx gas | Δ vs C0 |
| --- | ---: | ---: | ---: |
| C0 canonical | 154,450 | 185,722 | — |
| C5 lean events | 145,325 | 176,609 | **−9,125 exec (−5.9%) / −9,113 tx (−4.9%)** |

## Verdict

**Optional keep for gas-sensitive deployments.** Meets 5% observable trade-off threshold; not behavior-equivalent for indexers expecting canonical event schema.
