# C3 — Single-redemption fast path

## Purpose

When the outer batch contains exactly one redemption (`batchSize == 1`), avoid allocating `Delegation[][]` / `bytes32[][]` matrices and run `_redeemSingle` with flat memory.

## Semantic delta

- **Retained:** All four hook phases, validation order, events, forwarding for `batchSize == 1`.
- **Lost:** None for hot path; multi-batch outer batches use canonical matrix path.

## Benchmark

```bash
forge test --isolate -vv --match-contract CompatibleAblationGasBenchmark --match-test test_bench_C3
```

## Verdict

**Keep for limit-order hot path.** Meets ~2% exec threshold on representative single-redemption flow; safe per differential + forwarding spy tests.
