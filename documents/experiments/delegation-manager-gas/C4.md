# C4 — Fused validation loop (medium risk)

## Purpose

Merge signature validation and authority/disabled checks into one leaf-to-root pass per redemption instead of two separate loops.

## Semantic delta

- **Retained:** Atomic revert on any failed check; hooks still run only after full validation.
- **Lost:** None observed in differential tests; medium risk if future hooks depend on partial validation side effects.
